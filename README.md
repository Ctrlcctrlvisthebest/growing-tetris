# Growing Tetris

一个会在下落过程中不断生长的俄罗斯方块网页游戏。

## 操作

- `←` / `→`：移动
- `↑`：顺时针旋转
- `Z`：逆时针旋转
- `X`：旋转 180°
- `↓`：加速下落
- `Space`：直接落下
- `C`：存储或交换方块；每回合只能使用一次
- `F`：使用冻结道具，停止生长 8 秒
- `P`：暂停或继续游戏
- `H`：切换普通/困难模式并重新开局
- `R`：重新开始

旋转采用标准 Super Rotation System（SRS）：七种方块使用标准出生姿态和旋转中心，I 方块与 J/L/S/T/Z 方块分别使用对应的官方踢墙表。O 方块原地旋转；180° 旋转按两次连续的 SRS 90° 旋转处理。

棋盘中的灰色粗边框会显示当前方块垂直下落后的最终位置，并会随移动、旋转和生长实时更新。

困难模式中，第一次操作显示下一次生长位置，第四次操作让该位置生长；之后每四次操作重复这一循环。

普通模式可以使用棋盘左侧 Freeze 下方的拉杆调整生长速度。游戏每锁定 5 个方块提升一个速度等级，每级只小幅提速，并在棋盘右侧显示 `SPEED UP!`。困难模式由操作次数控制生长，因此拉杆和自动提速不生效。

勾选 `Directed growth` 后，方块固定横向向右生长。闪烁期间旋转方块，提示会重新出现在旋转后结构的右侧，可以借此控制下一次生长的位置。

每消除一行会获得 1 个冻结道具；多行同时消除会获得多个。冻结期间普通模式和困难模式都不会生长。
